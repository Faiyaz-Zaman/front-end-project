# Responsive Web Project

This is a simple, fully responsive web project built using **HTML**, **CSS**, and **JavaScript**. The layout adapts to different screen sizes using **media queries**, ensuring an optimal user experience across devices.

## Features

- HTML 
- Clean CSS styling
- JavaScript interactivity
- Fully responsive design using media queries

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Media Queries for responsiveness
